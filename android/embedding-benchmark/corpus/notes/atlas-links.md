# Links after splitting the Atlas handbook

The staff called both the binder and its PDF chapter “Index.” Each team copied it into a separate folder and kept a local link. A glossary can use a fully-qualified path when it deliberately links across departments.

For an unqualified name shared by several notes, resolve to the sibling of the referring note when available.

When updating incoming links after a move, change the destination path while preserving the fragment and the display label.
